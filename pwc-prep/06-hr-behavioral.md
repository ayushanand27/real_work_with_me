# 6. HR / Behavioral / Project Round

## Always have ready
1. **Tell me about yourself** (60-90 s): name/degree/college -> main skills (Salesforce, SQL, DSA, language) -> your Recruiting App project -> 1 achievement -> why PwC.
2. **Why PwC?** Global consulting + technology; large Salesforce/CRM practice; learning culture; exposure to client projects; I like solving business problems with technology.
3. **Why Salesforce?** Leading CRM, low-code + code, huge demand, quick delivery of business value; Trailhead makes learning hands-on.
4. **Strengths / weaknesses**: pick real ones. Weakness example: "I used to dive into code before planning; now I write the approach first."
5. **Project walkthrough**: use the script in `02-recruiting-app-project.md`.
6. **Challenge you faced** (STAR: Situation, Task, Action, Result): e.g. a trigger hit "Too many SOQL queries" -> moved query out of the loop and used a Map -> passed the 200-record bulk test.
7. **Teamwork / conflict / deadline** examples (use college projects/internships).
8. **Where do you see yourself in 5 years?** Growing into a Salesforce consultant/architect, certified, leading modules.
9. **Are you willing to relocate / work in shifts?** Have an honest answer.
10. **Questions for the interviewer**: "What does a typical project/team look like for a new joiner?", "What training/certification support is there?", "What would success look like in the first 6 months?"

## Do's
- Speak only about what you've actually built and can explain. If unsure: "I haven't implemented that, but my understanding is... and here's how I would approach it."
- Think aloud on coding questions; ask clarifying questions; test with an example.
- Keep a Developer Org open (or screenshots/recorded demo) as proof of the project.
- Join 10 min early, check mic/camera/internet, keep resume + water ready.
